# Mirai Graph contract gate

The repo-local graph is valid only when its listed objects, relations, and raw
source references match the canonical English `$docara` skill.

Run the read-only source contract before consuming a runtime context:

```bash
python3 scripts/mirai_graph_contract_gate.py
```

Use the active federation's Skill Sync Gate after changing `SKILL.md`, rules,
references, graph specifications, or repository recipes. Generated graph
reports do not grant canonical writes, installation, enablement, release, or
deployment authority.
